# Shadow Ascension · v0.8 «Клинки Бездны»

Одностраничная ARPG-рогалик в духе Solo Leveling — целиком в одном файле `index.html`, без сборки и зависимостей.

## Запуск

Любой статический сервер, например:

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

Или просто открыть `index.html` в браузере (прогресс хранится в localStorage).

## Управление

| Клавиша | Действие |
|---|---|
| **WASD / стрелки** | движение |
| **ЛКМ (зажать)** | комбо-атака кинжалами (3-й удар — усиленный) |
| **Q** | Вихрь Клинков (AoE + яд) |
| **E** | Метательные Кинжалы (веер + яд) / взаимодействие у врат |
| **R** | Рука Правителя (стягивает и взрывает врагов) |
| **F** | Шаг Сквозь Тень (рывок + невидимость; атака из тени = крит-«УБИЙСТВО») |
| **X** | **АРИЗ!** — извлечение тени из павшего врага |
| **C** | Обмен Тенями (местами с ближайшей тенью) |
| **SPACE** | Пробуждение Монарха (ульта при полной ярости) |
| **1 / 2** | зелье лечения / маны |
| **Tab** | сумка · **M** — звук · **Esc** — настройки/закрыть окна |

На телефоне: виртуальный джойстик, кнопки атаки, «АРИЗ!» и панели справа.

## Игровой цикл

**Мир** (хаб) → по таймеру открываются **Врата** случайного ранга (E→S, живут 60 с) → зачистка подземелья (волны + элита + босс) → врата выхода → награда → новые врата. С каждых 3 зачисток открывается следующий ранг. На рангах A/S встречаются **Алые врата** (Дворцы Демонов) с владыками и реликвиями. Тени, поднятые «АРИЗ!», сражаются рядом и растят **Власть Теней**.

## Что нового в v0.8

- **Восстановлен бой врагов** — в v0.7 у мобов не было кода начала атаки: гончие, солдаты, маги, палачи и рыцари не могли нанести ни одного удара. Теперь есть замах (телеграф), удары, болты магов и слэм Палача по площади.
- Leash-агро: обычные враги отстают на дистанции >20 клеток.
- Навыки больше не срабатывают при открытых окнах интерфейса.
- Миникарта корректно вписана в холст (ранее обрезалась).
- Ярлык «CRIT!» только у реальных критов (не поверх полученного урона).
- NaN-защита HP/MP при загрузке старых сейвов; реген не работает у мёртвого.
- Автосохранение при сворачивании вкладки/уходе со страницы.
- Разблокировка звука на iOS по первому касанию; Enter в поле имени; фавикон.
- Счётчик «врагов осталось» в подземелье.

Прогресс: localStorage-ключ `shadow_ascension_v4` (сейвы v2/v3 мигрируются автоматически).
