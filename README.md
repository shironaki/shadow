# Shadow Ascension · v0.12 «Ясность»

Изометрическая ARPG-рогалик о властителе теней — модульный проект без сборки: `index.html` (разметка+CSS) и 9 модулей в `js/` (движок, данные, мир, спрайты, сущности, тени, бой, UI, главный). Никаких зависимостей и билд-степов.

## Запуск

Любой статический сервер, например:

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

Или просто открыть `index.html` в браузере (классические скрипты грузятся по порядку; прогресс хранится в localStorage).

## Структура (v0.9)

| Модуль | Ответственность |
|---|---|
| `js/engine.js` | утилиты, звук, ввод (клавиатура/мышь/джойстик), камера, свет, физика |
| `js/data.js` | навыки, враги (ET), ранги теней (GDN/GDM), предметы, квесты, состояние G |
| `js/world.js` | генерация хаба и подземелий, палитры сцен, пререндер пола |
| `js/sprites.js` | процедурные спрайты всех персонажей и объектов |
| `js/entities.js` | игрок, враги, тени, Власть Теней |
| `js/shadows.js` | ИИ армии: стойки, приказ-цель, отзыв |
| `js/combat.js` | удары, навыки, урон, врата, волны, руда, цикл update() |
| `js/ui.js` | рендер сцены, HUD, панели, настройки, паспорт |
| `js/main.js` | сохранения, старт, игровой цикл |

## Управление

| Клавиша | Действие |
|---|---|
| **WASD / стрелки** | движение |
| **ЛКМ (зажать)** | комбо-атака кинжалами (3-й удар — усиленный) |
| **Q** | Вихрь Клинков (AoE + яд) |
| **E** | Метательные Кинжалы (веер + яд) / взаимодействие у врат |
| **R** | Рука Правителя (стягивает и взрывает врагов) |
| **F** | Шаг Сквозь Тень (рывок + невидимость; атака из тени = крит-«УБИЙСТВО») |
| **X** | **АРИЗ!** — извлечение тени из павшего врага |
| **V** | приказ армии: Штурм → Оборона → Стой (циклом) |
| **T** | отзыв всех теней к игроку |
| **C** | Обмен Тенями (местами с ближайшей тенью) |
| **SPACE** | Пробуждение Тени (ульта при полной ярости) |
| **1 / 2** | зелье лечения / маны |
| **Tab** | сумка · **M** — звук · **Esc** — настройки/закрыть окна |

На телефоне: виртуальный джойстик, кнопки атаки, «АРИЗ!» и панели справа.

## Игровой цикл

**Мир** (хаб) → по таймеру открываются **Врата** случайного ранга (E→S, живут 60 с) → зачистка подземелья (волны + элита + босс) → врата выхода → награда → новые врата. С каждых 3 зачисток открывается следующий ранг. На рангах A/S встречаются **Алые врата** (Дворцы Демонов) с владыками и реликвиями. Тени, поднятые «АРИЗ!», сражаются рядом и растят **Власть Теней**.

## Что нового в v0.12 «Ясность»

- **Лут-лучи**: над каждым дропом — столб света цвета награды (золото/кристаллы/реликвии/зелья/предметы). Дроп видно издалека.
- **Голова Soul Knight**: череп-«яйцо» с подбородком вместо шара, глаза с верхним веком и двойным бликом, брови у героя, ушки, румянец, объёмная чёлка крупными прядями с бликом на волосах.
- **Фикс @16**: у палитр Брута и Камиша отсутствовал `plateHi` → `addColorStop(undefined)` → страница падала при загрузке (с v0.10.1). Палитры дополнены, `lgg()` теперь устойчив к undefined.

## Что нового в v0.11.1

- **Хотфикс**: при наличии сейва загрузка страницы падала с `Cannot set properties of null (setting 'textContent')` — кнопка «НОВАЯ ИГРА…» переименовывалась до того, как создавалась. Экран старта оставался без кнопок. Текст теперь задаётся прямо в шаблоне; добавлен регрессионный тест «intro при сейве».

## Что нового в v0.11 «Пути Силы»

- **Классовые наборы Q/E/R/F**: у каждого класса — свой набор навыков, клавиши те же. Кнопки скиллбара и панель прокачки перестраиваются под класс.
  - **Тень** (исходный): Вихрь Клинков · Метательные Кинжалы · Рука Владыки · Шаг Сквозь Тень.
  - **Страж**: Сокрушающий Удар (×2.2 + стан) · Щит-Волна (отброс + 3с Отпора — отражение урона) · Бастион (4с −60% входящего урона, купол) · Натиск Щита (чардж, сносит и станит на пути).
  - **Чародей**: Вспышка Тьмы (нова) · Копья Тьмы (3 снаряда, каждое пробивает до 3 целей) · Разлом (стягивает и взрывается в точке прицела) · Прыжок Тени (телепорт до 4.5 клеток).
- **F теперь прокачивается** за золото у всех классов; старые сейвы мигрируются автоматически.
- **Версионирование скриптов** (`?v=0.11`): браузер больше не подтягивает старые модули из кэша — фикс «ошибок» после обновлений.
- Ультимейт (SPACE), АРИЗ (X) и Обмен тенями (C) остаются общими для всех классов.

## Что нового в v0.10.1 «Чиби»

- **Плащ у героя убран**, плащи врагов укорочены под чиби-пропорции.
- **Выбор героя при наличии сейва**: кнопка «Новая игра…» сначала раскрывает панель имя/пол/класс, старт — повторным кликом.

## Что нового в v0.10 «Путь Охотника»

- **Выбор пола**: мужчина/женщина при создании героя — своя фигурка, лицо и портрет (длинные волосы, мягкие черты).
- **Классы**: **Тень** (ассасин, +крит), **Страж** (+22% HP, −18% входящего урона, чуть медленнее), **Чародей** (+25% маны, навыки −25% по мане, быстрый реген). Класс виден в статусе.
- **Читаемость мира**: пол светлее, стены — приподнятые светлые плиты с тёмными гранями, контактные тени на границе стены и пола. Проходы и глухие углы больше не нужно угадывать.
- **Персонаж перерисован**: торс короче, ноги длиннее (человечные пропорции), компактная голова.
- **АРИЗ переработан**: шанс растёт с уровнем охотника против уровня врага (виден в процентах), провал больше не сжигает тело — можно пробовать снова, каждая попытка +15%. Починены боссы с нулевым шансом (Камиш, Игрис, Баран теперь поднимаются как боссы — 42%+).
- **Тени не разбегаются**: leash 8 клеток — дальше цели сбрасываются, на 12+ тень возвращается к вам.
- **Лор очищен**: убраны отсылки к «Сон Джин-Ву» и «Монарху» — ульта теперь «Пробуждение Тени», реликвии «Клинок Гадюки»/«Кинжал Вихря»/«Сердце Владыки», дефолтные имена «Охотник/Охотница».

## Что нового в v0.9 «Владыки»

- **Модульный движок**: монолит разрезан на 9 модулей `js/` (классические скрипты, без сборки). Тестовый стенд переведён на локальный HTTP с загрузкой всех модулей.
- **Золотые мега-врата** (после 9 зачисток, шанс 16%): внутри ждёт мегабосс — **Беллион, Гроссмейстер Теней** или **Беру, Король Муравьёв** (сильнее владык Дворца). Награда: двойная реликвия, 25 кристаллов, эссенция ×8. Тело мегабосса через «АРИЗ!» даёт **тень-Легенду** — 5-й ранг армии (×2.7 силы, пурпурная аура).
- **Полное управление армией теней**: стойки **Штурм** (радиус 10), **Оборона** (держатся рядом, бьют близких), **Стой** (стоят на месте) — клавиша **V** или чип под бейджем армии; кнопки в окне «Армия Теней». **Приказ-цель**: армия фокусирует врага, которого вы ударили последним (8 с, золотой маркер). **Отзыв** — **T** или кнопка: все тени переносятся к вам.
- **Добыча руды**: в подземельях кристаллы стали жилами (3 удара, шкала HP над жилой) — золото, материалы, 20% самоцветы, 8% кристаллы Власти. Добытая жила исчезает.
- **Подбор лута**: радиус поднятия 0.55→0.8 клетки, магнит 2.6→3.4 — меньше беготни по полу.
- **Новый портрет героя** — спокойный взгляд, слоистые градиенты, рим-лайт; **перерисована фигурка** — человечные пропорции, прямая осанка, длинное пальто.
- **Повороты тела**: корпус наклоняется к направлению прицела (атаки) и движения; у врагов замах отклоняет корпус назад, выпад — вперёд.
